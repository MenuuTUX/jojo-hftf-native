## Game files in this repository

`assets/disc/`, `assets/xa/` and `disc/SLUS_010.60` are files extracted from the game disc: the executable, overlays, character and stage data, sprites, palettes and audio. The repository owner states that they have Capcom's permission to include them. Do not redistribute them outside this repository unless you have your own permission.

`generated/` and `src/game/` hold code derived from the game's code (the recompilation and native translations of it).

The disc image itself is not included. You supply your own.
